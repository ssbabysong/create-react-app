# 豆仓 Bean Vault

一个克制、留白的咖啡豆收藏 PWA：拍下豆袋，信息自动识别入仓，慢慢攒满产地、处理法与风味。

## 功能

- **拍照录入**：拍豆袋正面和背面（最多 3 张），用 Claude 识别名称、烘焙商、产地、产区、庄园、品种、处理法、烘焙度、用途、烘焙日、净重、价格、风味；识别结果只填你还没改过的字段，填完请核对
- **照片封面**：第一张照片作为封面；没有照片时显示极简的单线插画（手冲豆画手冲，意式豆画浓缩杯）
- **赏味追踪**：按烘焙天数和用途分成「最佳赏味 / 养豆中 / 尽快喝完 / 已喝完」
- **称豆记录**：一键「冲一杯」扣余量，详情页可自定义克数，保留使用记录；喝完可一键回购
- **图鉴**：产地、处理法、品种、风味收集进度和成就
- **备份**：导出 / 导入 JSON（包含照片）
- **PWA**：可添加到主屏幕、离线可用，支持深色模式

## 拍照识别的 API Key

识别需要一个 Anthropic API Key（在 console.anthropic.com 创建），在「图鉴 › 设置与备份」或录入页里填写。

- Key 只保存在当前设备的浏览器里，识别时由浏览器直接发送给 Anthropic（没有中间服务器）
- 因为 Key 存在浏览器里，这个方式适合自己用；不要把带 Key 的设备或数据分享给别人
- 默认使用 `claude-opus-5-5`，识别代码在 `src/extract.js`

不填 Key 也能用：照片照样做封面，信息手动填写。

## 数据存储

- 豆子数据：`localStorage`
- 照片：`IndexedDB`（`src/photos.js`）

## 开发

```bash
npm install
npm run dev      # 本地开发
npm run build    # 构建到 dist/
npm run preview  # 预览构建结果（Service Worker 只在生产构建中注册）
```

`dist/` 是纯静态文件，可部署到任意静态托管。插画和图标在 `src/components/Line.jsx`。
