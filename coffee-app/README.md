# 豆仓 Bean Vault ☕

收集向的咖啡豆管理 PWA：把每一支豆子收进豆仓，点亮产地图鉴、解锁成就。

## 功能

- **豆仓**：记录名称、烘焙商、产地/产区/庄园、品种、处理法、烘焙度、烘焙日、净重、价格、风味、评分、笔记和豆袋照片
- **新鲜度**：按用途（手冲/意式/两用）自动判断「养豆中 → 最佳赏味 → 尽快喝完 → 风味衰退」
- **一键称豆**：卡片上直接「手冲 −15g / 意式 −18g」扣余量，详情页可自定义克数，保留使用记录
- **回购**：喝完的豆子一键回购，新包重新入仓
- **图鉴**：26 个产地按大洲点亮，处理法 / 品种 / 风味收集进度
- **成就**：瑰夏初体验、非洲三杰、处理法大师、拉花练习生……
- **备份**：数据存在本机浏览器，可导出 / 导入 JSON
- **PWA**：可「添加到主屏幕」，离线可用，支持深色模式

## 开发

```bash
npm install
npm run dev      # 本地开发
npm run build    # 构建到 dist/
npm run preview  # 预览构建结果（Service Worker 只在生产构建中注册）
```

`dist/` 是纯静态文件，可部署到 GitHub Pages、Vercel、Netlify 等任意静态托管。
